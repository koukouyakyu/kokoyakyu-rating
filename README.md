# 高校野球 Rating - Prototype

高校野球部に独自Ratingを付与して公開するための、静的Webサイトのプロトタイプです。

## 収録機能
- 全国ランキング（検索・都道府県フィルター）
- 学校詳細（Rating推移、直近試合）
- 都道府県比較（平均・中央値・Top5平均・Top25%平均）
- 試合シミュレーター
- Rating計算方法の説明

## 現在のRatingルール
- 初期Rating: 1500
- 勝利: W=1
- 引き分け: W=0.5
- 敗戦: W=0
- 基本K値: 10
- 大会重要度補正: なし（プロトタイプ）
- シーズンリセット: なし
- 点差補正: なし

期待値:
`We = 1 / (1 + 10^(-D/600))`

更新:
`R' = R + K * (W - We)`

## 起動方法
`index.html` をブラウザで開くだけです。

ローカルサーバーを使う場合:

```bash
python3 -m http.server 8000
```

その後 `http://localhost:8000` を開きます。

## 公開
GitHub Pages / Cloudflare Pages / Netlify / Vercel などの静的ホスティングにそのまま配置できます。

## 注意
現在のランキング値・試合履歴はUI確認用のサンプルデータです。公開運用では、各大会の利用条件を確認したうえで公式戦の事実データを取り込み、自前のデータベースでRatingを再計算してください。
